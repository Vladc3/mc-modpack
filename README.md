# Modpack pro náš Minecraft server

Fabric **1.21.1**. Klient musí mít přesně stejné mody jako server, jinak tě nepustí dovnitř nebo vyhodí.
Stáhni si poslední verzi z [Releases](../../releases/latest).

## Instalace

**Modrinth App / Prism / Lunar (doporučeno)**
1. Stáhni `server-pack-1.21.1.mrpack`.
2. Modrinth App: *Add instance → From file*. Prism: *Add Instance → Import*. Lunar: *Versions → Modpacks* a soubor přetáhni.
3. Nastav RAM 4–6 GB a spusť.

**Oficiální launcher**
1. Nainstaluj [Fabric installer](https://fabricmc.net/use/installer/): Minecraft 1.21.1, loader 0.20.1. Zvol vlastní složku hry.
2. Stáhni `mods-1.21.1.zip` a rozbal ho do `mods` v té složce.
3. V profilu nastav RAM 4–6 GB (`-Xmx6G`).

**Aktualizace:** při nové verzi stáhni nový `.mrpack` (nebo smaž staré mody a rozbal nový zip). Staré mody nenechávej, vyhodí tě to.

## Jak hrát

Třídy, progrese výbavy, šperky, vesničané, kam za strukturami a všechny klávesy: **[GUIDE.md](GUIDE.md)**.

Nejdůležitější klávesy: `R` schopnost meče, pravý klik / `1`–`9` kouzla, `B` batoh, `M` mapa, `V` voice chat (mluvíš držením `Caps Lock`).

## Když něco nejde

Pošli Vovovi soubor `logs/latest.log` ze složky hry a napiš, co jsi zrovna dělal.
